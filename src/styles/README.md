# 样式组织

`src/style.css` 是唯一入口，仅维护导入顺序。新增和修改样式应进入对应文件，避免在入口末尾追加覆盖规则。

| 文件 | 范围 |
| --- | --- |
| `base.css` | 字体、重置、基础表单、通用辅助类 |
| `layout.css` | 页面布局、顶部栏、视图切换、底部状态栏 |
| `sidebar.css` | 地图列表、侧栏、探索状态 |
| `canvas.css` | 画布、标题、视图工具、3D 坐标轴 |
| `graph.css` | 节点、连线、端点、参考层 |
| `inspector.css` | 属性抽屉、节点设置、条件编辑 |
| `dialogs.css` | 弹窗、提示、校验结果 |
| `menus.css` | 地图菜单、右键菜单、画布内表单 |
| `select.css` | 通用下拉菜单、尺寸变体、楼层文本按钮 |
| `node-tools.css` | 共用节点卡片、数字、底部创建栏、轮盘布局 |

同一选择器的默认样式集中定义；状态和尺寸变体紧随基础规则。响应式规则放在所属文件末尾。修改共用卡片时，同时检查底部工具栏和右键轮盘。
